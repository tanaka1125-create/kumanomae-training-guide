# KUMANOMAE TRAINING

エニタイムフィットネス熊野前店の掲載設備に合わせた、身長175cm・開始85.5kg向けの4週間減量トレーニングサイトです。80.5kgをストレッチ目標として表示しつつ、公的ガイドラインに沿う安全な減量ペースを優先します。

## 内容

- 平日5日の曜日別メニュー
- 週末の回復ウォークを含む週175～225分の段階的な有酸素計画
- 7,000歩から8,000歩へ増やす週別の活動目標
- 4週間の負荷進行
- RPE・セット・回数・休憩
- 全種目に固定したYouTubeフォーム解説動画
- 平日5日を強弱に分けた、別枠のアブローラー4週間プラン
- アブローラーの曜日別セット・回数・強度・休憩と実績記録
- 端末内に保存される重量・回数・週平均体重・歩数・有酸素時間・食事記録日数・腰痛記録
- 85.5kgから80.5kgまでの減量進捗表示
- 休憩タイマー
- 腰痛時の中止基準と受診目安

このサイトは一般的な運動計画であり、診断や治療の代替ではありません。

## 減量目標の扱い

- 5kg／4週は週1.25kgに相当するため、ストレッチ目標として扱います。
- 安全運用の目安は週0.5～0.9kgです。
- 1日500～750kcal程度の差を食事と活動の組み合わせで作り、極端な食事制限は行いません。
- 筋トレは週3日、有酸素は週175分から段階的に増やし、4週目は回復を優先します。

参考：CDC、米国HHS身体活動ガイドライン、厚生労働省「健康づくりのための身体活動・運動ガイド2023」、NIDDK。
