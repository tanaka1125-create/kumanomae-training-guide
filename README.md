# KUMANOMAE TRAINING

エニタイムフィットネス熊野前店の掲載設備に合わせた、未経験者向け4週間トレーニングサイトです。

## 内容

- 平日5日の曜日別メニュー
- 4週間の負荷進行
- RPE・セット・回数・休憩
- 全種目に固定したYouTubeフォーム解説動画
- 端末内に保存される重量・回数・体重・腰痛記録
- 休憩タイマー
- 腰痛時の中止基準と受診目安

## ローカル確認

```text
npm run dev
```

## 検証

```text
npm test
npm run build
```
